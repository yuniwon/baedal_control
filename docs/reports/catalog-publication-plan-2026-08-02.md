# 새 메뉴 플랫폼 전파 계획

## 목표

새 메뉴를 통합메뉴에 저장할 때 전파 대상 플랫폼을 한 번 선택하고, 각 플랫폼에서 기존 메뉴 연결·자동 생성·수동 등록·차단 상태를 한 화면에서 확인한다. 플랫폼별 생성 방식이 다르므로 통합메뉴가 플랫폼 화면을 직접 가정하지 않고 생성 writer 계약으로 확장한다.

## 현재 동작

- 새 메뉴 생성 화면은 모든 플랫폼을 기본 전파 대상으로 선택한다.
- `등록 방식 확인`을 먼저 실행해야 통합메뉴 저장이 가능하다.
- 선택한 전파 의도(`publish`/`exclude`)는 메뉴별로 저장된다.
- 이미 연결된 메뉴는 중복 생성하지 않고 연결 유지로 표시한다.
- 생성 writer가 검증된 플랫폼만 향후 자동 등록 대상으로 분류한다.
- 생성 화면은 확인됐지만 최종 저장·재수집 검증이 없는 플랫폼은 수동 등록으로 분류한다.
- 원본 수집/생성 경로가 없는 플랫폼은 등록 차단으로 분류한다.

## 자동 등록을 켜는 조건

플랫폼별 `PlatformCatalogCreator`를 구현하고 다음을 모두 확인한 뒤 `menuCreation`을 `verified`로 승격한다.

1. 로그인 세션과 가게 식별을 확인한다.
2. 메뉴명·가격·사이즈·옵션·이미지 규격으로 생성 요청을 구성한다.
3. 저장 후 새 메뉴 ID와 화면의 성공 표식을 확인한다.
4. 다시 수집해 통합 기준과 실제 플랫폼 원본이 일치하는지 검증한다.
5. 실패·중복·부분 성공을 기록하고 같은 메뉴의 재시도를 멱등적으로 막는다.

현재는 이 검증을 통과한 플랫폼이 없으므로 실제 자동 생성 호출을 하지 않는다. 배민의 생성 마법사는 읽기 전용 점검만 완료된 상태이며, 나머지 플랫폼은 생성 writer가 아직 없다.
