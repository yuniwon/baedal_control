# 통합 가격 구조 투영 미리보기

## 목적

통합메뉴의 M/L/F 가격을 플랫폼에 저장하기 전에, 각 플랫폼이 실제로 사용하는 구조로 어떻게 표현되는지 읽기 전용으로 확인한다. 이 단계에서는 원본 메뉴·옵션·매핑을 변경하지 않는다.

## 판정 방식

- `필수 사이즈 옵션`: M/L 선택지가 있는 필수 옵션 그룹(최소=최대=1)을 유지하고, 통합 기준 가격과 옵션 증액을 함께 표시한다.
- `플랫폼 메뉴 분리`: 요기요처럼 M/L이 별도 원본 메뉴로 수집되는 경우 두 원본 ID를 한 통합메뉴 아래에 남긴다.
- `가격행 사용`: 한 플랫폼 메뉴에 M/L/F 가격행이 직접 수집된 경우 가격행으로 표시한다.
- `단일 메뉴`: 패밀리·콰트로처럼 독립 메뉴로 판매되는 대형 메뉴는 일반 M/L과 합치지 않는다.

통합메뉴에 L 가격이 명시되지 않았거나 원본 가격이 기준과 다르면 `검토 필요`로 표시한다. 리뷰 이벤트, 세트, 두판·반반 메뉴는 size sibling 병합 대상에서 제외되며, 투영 미리보기에서도 원본 매핑을 별도로 유지한다.

## 사용

통합메뉴 화면의 `가격 구조 미리보기` 버튼을 누르면 플랫폼별 대상 수·확인/검토 수와 메뉴별 투영 방식·가격·경고를 확인할 수 있다. CLI에서도 다음 명령으로 현재 DB를 읽을 수 있다.

```text
npm run catalog:projection -- --db <delivery-menu-sync.db 경로>
```

현재 쓰기 지원이 확인되지 않은 플랫폼은 이 미리보기 결과를 기반으로 수동 검토 후 별도 업로드 단계에서 처리한다.
